# P3NROSE レベルエディタ

この段階ではレベルエディタと、そのステージを確認するテストプレイ画面を実装しています。ゲーム本編のタイトル・進行・クリア演出は未実装です。

## 起動

P3NROSE フォルダで `npm run serve` を実行し、`http://localhost:8000/editor.html` を開きます。Node.js 以外の依存は不要です。`npm test` で座標、辺・頂点、外周、確定配置探索、テストプレイ判定を確認できます。

## エディタ操作

- 右の THIN / FAT を掴んで盤面へ運び、指やマウスを離して配置します。タイル置き場をクリックして種類を選び、盤面をクリックする操作もできます。
- 最初のタイルは盤面の基準になります。2枚目以降は合法な隣接位置に置きます。「確定配置探索」を押すと、Penrosanne の高速テンプレート探索による確定位置と円弧を細い線で描きます。探索は押した時だけ行います。探索結果はJSONへ保存しません。
- 確定位置を表示中は、その位置と隣接位置にもタイルを置けます。配置済みタイルは動かせません。エディタでは右クリックで削除します。
- タイルまたは確定位置の辺を左クリックすると黄色い外周辺を追加し、黄色い辺を右クリックすると削除します。「外周自動作成」は現在の配置全体の外周を指定します。
- 外周の外に出る点線の直線をクリックすると、色付き実線 → 灰色実線 → 灰色点線 → 色付き実線の順に変わります。「記号ランダム選択」はこの3状態をシャッフルします。
- 「初期表示タイル選択」を押した後、配置済みタイルをクリックすると、テストプレイ開始時から固定するかを切り替えられます。
- 「全体を回転」は選択した角度で盤面の表示を回します。「全体リセット」は5秒以内に2回押すと、選択中ステージのタイル・外周を消去します。
- ステージ番号をドラッグして別の番号へ落とすと並べ替えられます。下書きはブラウザに自動保存されます。JSON書出し・読込みにも対応します。

## テストプレイ

黄色い辺が分岐や交差のない1本の環になり、配置済みタイルにルール違反がないと開始できます。本編風の画面に切り替わり、最初から固定したタイル以外は空欄になります。THIN / FAT を盤面にドラッグして外周内を埋めます。エディタの灰色点線はテストプレイでは表示されず、灰色実線は円弧の接続位置だけを示し、色付き実線は位置と赤・青の両方を指定します。配置済みタイルは再びドラッグして移動でき、候補のない場所へのドロップや右クリックで消えます。合法な180°回転が可能なときだけタイル中央に回転ボタンが出ます。固定タイルは上面を背景色 #294845、側面を盤面の内壁色で描き、移動・削除できません。「すべてリセット」は固定タイルだけを残します。左上のボタンでエディタへ戻れます。

## データと現在の範囲

JSONは `schemaVersion: 2` のステージ配列で、配置したタイル、固定タイルID、黄色い外周辺と記号の表示状態、盤面の表示角度を保存します。確定配置は再探索する一時表示です。別解の一意性判定と製品版の進行保存は、ゲーム本編の実装時に追加します。

仕様の基礎は [docs/GAME_SPECIFICATION.md](docs/GAME_SPECIFICATION.md) を参照してください。添付の画面図とユーザー指定による変更は同文書の追補に記録しています。
